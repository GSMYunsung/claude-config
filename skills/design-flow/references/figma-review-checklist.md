# Figma 디자인 검수 체크리스트

Phase 4에서 사용. 각 항목을 스크린샷과 함께 확인한다.

---

## 카테고리 1: 타이포그래피

| # | 항목 | 확인 방법 |
|---|------|----------|
| T1 | 모든 텍스트가 Local Styles(Text Styles)에서 정의된 스타일만 사용 | Selection → Text 패널에 style 이름 표시 여부 |
| T2 | 폰트 패밀리가 브리프에 정의된 것만 사용 | Edit → Select All with Same Font 로 이탈 요소 탐색 |
| T3 | 위계가 명확함 (Display > H1 > H2 > Body > Caption) | 각 텍스트 크기 비율 육안 확인 |
| T4 | Line-height 설정이 일관됨 (Inspect 패널에서 수동값 없음) | Inspect → Line height auto vs 수동값 |
| T5 | 모바일 프레임에서 텍스트 잘림 없음 | 375px 프레임 전체 스크롤 확인 |
| T6 | 코드/라벨용 Mono 서체가 지정된 곳에만 사용됨 | — |

## 카테고리 2: 컬러 & 토큰

| # | 항목 | 확인 방법 |
|---|------|----------|
| C1 | 모든 fill/stroke가 Local Styles(Color Styles) 사용 — 수동 hex 없음 | Edit → Select All → Inspect에서 raw hex 탐색 |
| C2 | 사용된 컬러가 브리프 팔레트(4–6개) 안에서만 존재 | Local Styles 패널에서 정의 외 항목 없는지 확인 |
| C3 | 배경 위 본문 텍스트 대비비 ≥ 4.5:1 (WCAG AA) | Figma Plugin: Contrast 또는 A11y Annotation Kit |
| C4 | 강조색(accent) 위 텍스트 대비비 ≥ 4.5:1 | 동일 |
| C5 | 다크모드 / 라이트모드 지원 여부 확인 (지원 시 양쪽 모두 확인) | — |

## 카테고리 3: 레이아웃 & 간격

| # | 항목 | 확인 방법 |
|---|------|----------|
| L1 | 반복 요소 사이 간격이 일관됨 (동일 간격값 사용) | Inspect → spacing 숫자가 동일한 단위(8px 배수) 사용 여부 |
| L2 | Auto Layout이 적용된 컴포넌트에서 Hug/Fill 설정 올바름 | Frame 선택 → Constraints/Resizing 확인 |
| L3 | 레이아웃 그리드를 기준으로 요소가 정렬됨 | View → Layout Grids 켜고 육안 확인 |
| L4 | Section 간 여백이 일관됨 (상/하 padding 동일 단위) | — |
| L5 | 브리프 와이어프레임과 전체 구조가 일치함 | brief.md 와이어프레임과 나란히 비교 |

## 카테고리 4: 컴포넌트 일관성

| # | 항목 | 확인 방법 |
|---|------|----------|
| P1 | 반복되는 UI 요소(카드, 버튼, 태그 등)가 Component로 정의됨 | Assets 패널에서 확인 |
| P2 | 같은 컴포넌트의 인스턴스가 일관된 Variant 사용 | 인스턴스 선택 → Variant 드롭다운 확인 |
| P3 | Interactive State(hover, focus, active)가 Variant로 정의됨 | Component → Variants 패널 |
| P4 | 독립적으로 사용되는 아이콘이 Component 처리됨 | — |

## 카테고리 5: 접근성

| # | 항목 | 확인 방법 |
|---|------|----------|
| A1 | 링크/버튼의 Focus 상태가 명시적으로 디자인됨 | Variant: focused 상태 존재 여부 |
| A2 | 아이콘만 있는 버튼에 accessible label 주석 있음 | Annotation 레이어 또는 주석 처리 |
| A3 | 색상만으로 정보를 전달하는 곳 없음 (아이콘/텍스트 병기) | 컬러 제거 후 의미 전달 가능한지 확인 |
| A4 | 텍스트 최소 크기 ≥ 12px (가독성 기준) | Inspect → font size 확인 |
