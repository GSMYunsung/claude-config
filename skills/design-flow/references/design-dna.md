# Design DNA 파이프라인

출처: https://github.com/ryanthedev/design-for-ai (`references/visual/design-dna.md`, `references/visual/archetypes.md`)  
목적: 분포 중앙값(AI 기본값)에서 벗어난 의도적 디자인 방향을 수립하는 5단계 프로세스.

---

## 왜 DNA인가

모델은 "깔끔하고 모던한" 디자인을 요청받으면 학습 코퍼스의 통계 평균을 반환한다. 같은 폰트, 같은 그라디언트, 같은 카드 그리드. DNA는 타입/컬러/컴포지션/모션 4개 축을 서로 다른 레퍼런스 패밀리에서 빌려 조합함으로써 이 수렴을 강제로 깬다.

---

## The Pipeline: Ground → Diverge → Critique → Converge → Gate

### 1. Ground — 후보당 2개의 네임드 레퍼런스

생성 전에 구체적인 레퍼런스 2개를 고른다. "깔끔한 SaaS"처럼 분포를 지칭하는 것은 허용하지 않는다. 구체적인 프로덕트, 출판물, 물리적 오브젝트를 명시한다.

형식:
> **[레퍼런스 A의 특정 속성] + [레퍼런스 B의 특정 속성]**  
> 예: "Linear의 타이포그래피 규율 + Pitchfork의 에디토리얼 컬러"

한 레퍼런스는 클론 목표가 되므로 반드시 두 개를 고른다. 두 레퍼런스의 충돌 지점이 DNA를 정의한다.

### 2. Diverge — 3~5개 후보 강제 분기

후보들 간에 레퍼런스 쌍이 겹치지 않아야 한다. 색조 패밀리도 분산시킨다. 목표는 서로 완전히 다른 시각 언어를 가진 후보들의 집합.

### 3. Critique — 선택 전 기준 기반 비판

모든 후보에 대해 하나의 비판 패스를 수행한다. 기준:
- **독특함**: 이 조합이 훈련 데이터의 어떤 클러스터와도 다른가?
- **레지스터 적합성**: 이 디자인의 목적·대상에 맞는가?
- **Tell 스캔**: `ai-tells.md` 체크리스트 통과하는가?

선택은 비판 *이후*에만 한다.

### 4. Converge — 선택, 합성, 또는 1회 재순환

세 가지 옵션:
- 후보 하나 선택
- 두 후보의 특정 축을 합성 (예: A의 타입 + B의 컬러)
- 단 1회 루프백 허용 (새로운 발산 라운드)

### 5. Gate

DESIGN.md (또는 brief.md)가 잠기기 전까지 다운스트림 작업 없음.

## 4개 축 (Four Axes)

모든 DNA는 4개 축 전체를 명시한다.

| 축 | 범위 | 포지션 예시 |
|---|---|---|
| **Type voice** | 디스플레이 + 바디 폰트, 스케일 비율, 웨이트 범위, 리딩 | "Fraunces 디스플레이 / Karla 바디, 1.333 비율, 넓은 리딩" |
| **Color strategy** | 시드 색조, 채도 성격, 배경 방식, 하모니 규칙, 강조색 수 | "Moss 시드(h150), 뮤트 채도, 웜 페이퍼 배경, 유사색, 강조 1개" |
| **Composition** | 그리드 성격, 밀도, 반경, 테두리/그림자, 대칭, 지배 요소 | "스위스 그리드, 헤어라인 룰, 제로 반경, 플러시 왼쪽" |
| **Motion vocabulary** | 타이밍 범위, 이징 성격, 허용 움직임, 시그니처 전환 | "상태 전용, 150ms, 샤프 ease-out, 값 카운트 트랜지션" |

**Remix 규칙:**
- 베이스 패밀리의 기본값을 모든 축에 적용한다
- 다른 패밀리에서 정확히 1~2개 축만 빌린다 (0개 = 클론, 3개 이상 = 일관성 없음)
- **한 축이 지배해야 한다.** 이 디자인의 정체성을 어떤 축이 담당하는지 명시한다
- 컬러 전략과 컴포지션을 동시에 빌리지 않는다 (방을 두 번 바꾸는 것)

## 시그니처 무브

모든 DNA에는 **단 하나의 시그니처 무브**가 포함된다: 템플릿이 절대 만들어내지 못할 결정.

예시 유형:
- 120px Fraunces 섹션 번호가 왼쪽 마진에 고정
- 모든 인터랙티브 요소가 4px 오프셋 하드 그림자 공유
- 강조색이 현재 Nav 항목과 CTA에만 등장 — 다른 곳에는 절대 없음
- 헤딩이 맵 프레임 레전드처럼 상단 테두리를 가로지름

하나의 무브, 일관된 실행. 다섯 개의 잡기보다 낫다.

## 12 Brand Archetypes

브리프의 목적·대상·성격 3개 단어에서 아키타입을 *도출*한다. 사용자에게 "어떤 아키타입인가요?" 묻지 않는다.

| 아키타입 | 핵심 욕구 | 시각적 중력 |
|---|---|---|
| **Innocent** | 안전, 단순함 | 부드러운 밝은 팔레트, 넉넉한 여백, 둥근 형태 |
| **Everyman** | 소속감 | 친근한 중간 대비, 익숙한 레이아웃 |
| **Hero** | 숙달, 용기 | 굵은 대비, 강한 원색, 자신감 있는 타입 웨이트 |
| **Outlaw** | 해방, 파괴 | 검정 + 강렬한 액센트, 부서진 그리드 |
| **Explorer** | 자유, 발견 | 어스톤, 열린 레이아웃, 비대칭 |
| **Creator** | 혁신, 자기표현 | 절제된 캔버스 + 표현적 레터폼, 디테일 |
| **Ruler** | 통제, 위신 | 깊은 톤 + 골드, 형식적 대칭, 세리프 |
| **Magician** | 변환 | 깊은 채도, 극적 명암, 그라디언트를 이벤트로 |
| **Lover** | 친밀감, 감각적 쾌락 | 진한 레드/블러쉬, 풍부한 질감 |
| **Caregiver** | 서비스, 보호 | 부드러운 블루/그린, 둥근 형태, 차분한 모션 |
| **Jester** | 기쁨, 놀이 | 밝은 클래싱 원색, 통통튀는 지오메트리 |
| **Sage** | 진실, 이해 | 뮤트 팔레트, 세리프 또는 테크니컬 타입, 데이터 중심 |

## 8 Aesthetic Families (포트폴리오 프로젝트 기준 추천)

| 패밀리 | 느낌 | 타입 | 컬러 | 맞는 아키타입 |
|---|---|---|---|---|
| **Editorial Minimalism** | 조용한 권위 | Newsreader/Fraunces + 좁은 그로테스크 | 웜 뉴트럴, 단일 뮤트 액센트 | Sage, Creator, Ruler |
| **Warm Editorial** | 핸드메이드 온기 | Fraunces/Lora + 휴머니스트 산세리프 | 테라코타/클레이/크림 | Caregiver, Lover, Innocent |
| **Swiss / International** | 1960년대 바젤 포스터 | 그로테스크 단일 패밀리 (Switzer 등) | 흑백 + 단일 채도 액센트 | Sage, Hero, Ruler |
| **Neo-Brutalist** | 자신감 있는 조잡함 | Archivo Black + 플레인 또는 모노 | 솔리드 2색 + 블랙 테두리 | Outlaw, Jester, Creator |
| **Terminal / Mono-Core** | TUI의 아름다움 | 모노스페이스 전체 (JetBrains Mono 등) | 근검정 배경 + 인광 액센트 | Sage, Outlaw, Explorer |
| **Data-Dense Professional** | Bloomberg + 타이포그래퍼 | 컴팩트 그로테스크 + 표형 숫자 | 뉴트럴 크롬 + 데이터용 채도 액센트 | Sage, Ruler, Hero |
| **Cinematic Dark** | 영화 타이틀 시퀀스 | 오버사이즈 디스플레이 | 딥 틴티드 다크 + 단일 발광 색 | Magician, Hero, Outlaw |
| **Playful Geometric** | Memphis 그룹이 SaaS를 만들면 | 라운디시 디스플레이 + 클린 바디 | 3-4 밝은 색조 (트라이아딕) | Jester, Innocent, Creator |

## design-for-ai AI Tells 핵심 (2026-07)

아래는 `references/visual/ai-tells.md`의 레드플래그 발췌. 전체 카탈로그는 원본 참조.

| 플래그 | 심각도 | 수정 방향 |
|---|---|---|
| Inter/Roboto 기본 폰트 | 높음 | 목적·성격에 맞는 폰트 선택 |
| 청록-어두운 팔레트 | 높음 | 무드 → 기본 색조 → 색상환 관계로 팔레트 재설계 |
| 모든 것을 카드로 | 높음 | 컨테인먼트가 필요한 곳에만 카드 사용 |
| 모든 텍스트 가운데 정렬 | 중간 | 바디 텍스트 왼쪽 정렬, 비대칭 레이아웃 |
| 동일한 간격 | 중간 | 그룹 내 tight, 그룹 간 generous 비례 간격 |
| 다크모드 + 네온 액센트 | 중간 | 콘텐츠·대상 기반 라이트/다크 결정 |
| 인디고-바이올렛 계열 강조색 | 높음 | `#6366F1`, `#8B5CF6`, `#A855F7` 사용 금지 |
| 0.1 불투명도 그림자 균일 적용 | 중간 | 깊이 변화 있는 그림자 설계 |
| Tailwind/shadcn 기본값 미수정 | 높음 | `--radius`, 간격 스케일, 그림자 커스터마이즈 |
| 크림+세리프+테라코타 군집 | 중간 | 의도적 에디토리얼 컨텍스트가 아니면 금지 |
| Space Grotesk 기본 폰트 | 높음 | 2025 추천 → 2026 금지 ("노력한 척") |
